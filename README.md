A Biblioteca Virtual de Jogos será uma plataforma digital que reúne e organiza diversos jogos em um único ambiente. O projeto pretende facilitar o acesso dos usuários aos jogos, permitindo pesquisar e conhecer diferentes opções de entretenimento. Também busca apresentar informações sobre cada jogo, como gênero, descrição e classificação, de forma simples e organizada.

Avaliação:

O HTML base está bem encaminhado para o momento do periodo, a marcação é semântica e coerente, com header, main, section e footer, a hierarquia de títulos vai certinha do h1 para os h2, e o formulário de cadastro está bem organizada, com fieldset e legend agrupando os campos, label ligado por for, e validações com required, minlength, min, max e type email.

Pontos positivos:
- metadados presentes e corretos
- link externo com target blank com de rel noopener noreferrer
- imagem com alt descritivo
- tabela com thead, tbody e th separando cabeçalho e corpo
- select com opção vazia inicial obrigando o usuário a escolher

Pontos a ajustar:
- o h2 Primeiro Trailer e o iframe ficaram soltos dentro do main, fora de qualquer section, o ideal seria fechar num section próprio para manter o padrão do resto da página
- o campo de e-mail não está como required, mesmo sendo o único contato de quem faz o cadastro

No geral é um projeto sólido e bem feito, os ajustes são mais de organização do que de correção.
